# 曼波机器狗（Mambo Robot Dog）

基于 **STM32F103C8T6** 的四足机器狗，支持语音控制、超声波避障、红外寻迹与姿态动作控制。
语音识别由 **ASRPRO** 模块完成，识别结果通过串口下发给主控；主控负责步态、避障与状态切换，并在 OLED 上显示当前状态。

> 课程项目 / 物联网方向。当前版本 **V2.0（2026-10-31）**

---

## 一、硬件组成

| 模块       | 型号 / 规格                                               | 说明                                                    |
| ---------- | --------------------------------------------------------- | ------------------------------------------------------- |
| 主控 MCU   | STM32F103C8T6（Cortex-M3，64KB Flash / 20KB RAM）         | Keil MDK 工程，标准外设库                               |
| 语音识别   | ASRPRO                                                    | 图形化编程，工程见 `语音存档/`                          |
| 语音合成   | ASRPRO                                                    | 播报提示音                                              |
| 舵机       | SG90 4个（型号 / 数量）（可以更换其他的，这个舵机声音大） | PWM 驱动，`Servo.c` + `PWM.c` + `Movement.c` 三文件协同 |
| 超声波测距 | HC-SR04                                                   | `UltrasonicWave.c`，定时器捕获回响                      |
| 红外传感器 | 常用的红外模块即可（型号）                                | `Hongwai.c`，边沿 / 避障检测                            |
| 显示       | （0.96/1.3）寸 OLED（I2C）                                | `OLED.c`，显示模式与测距值                              |
| PCB        | 立创 EDA 专业版工程(两层板)                               | `硬件PCB资料/ProPrj_新_曼波机器狗_2026-09-18.epro2`     |

### 串口分配

| 串口   | 用途                     | 波特率 |
| ------ | ------------------------ | ------ |
| USART1 | 调试输出（预留 H2 接口） | 9600   |
| USART2 | 语音模块指令             | 9600   |
| USART3 | 语音识别结果接收         | 9600   |

## 三、编译与烧录

1. 安装 **Keil MDK5** + STM32F1 器件支持包（Keil.STM32F1xx\_DFP）。
2. 用 Keil 打开 `软件代码/Project.uvprojx`。
3. `F7` 编译 → 生成 `Objects/Project.hex`。
4. 用 ST-Link / J-Link 下载到板子上的（c8t6开发板）。
5. 语音部分：用 ASRPRO 配套的图形化 IDE 打开 `语音存档/*.hd`，U转串模块（CH340等）烧录到 ASRPRO 模块。

> 编译产物（`Objects/`、`Listings/`、`*.hex`、`*.axf`）已在 `.gitignore` 中排除，克隆后需自己编译生成。

## 四、控制方式

主控通过串口接收 ASRPRO 下发的单字节指令，切换运行状态（`Mode.c` 中的状态机）：

| 指令 | 动作                |
| ---- | ------------------- |
| f    | 前进                |
| b    | 后退                |
| l/r  | 左转 / 右转         |
| q    | 站立 / 趴下         |
| x    | 避障模式 / 寻迹模式 |

## 五、注意事项

- **源码为 GBK 编码**。用 VSCode 打开 `main.c` 等文件若出现中文乱码，把文件编码切到 `GB2312 / GBK` 即可，**不要用 UTF-8 保存回去**，否则 Keil 里会变成乱码。
- 无密钥、无 WiFi 配置，可安全公开。
- `*.bak_*` 等手动备份文件已被忽略——版本回退请用 `git log` / `git restore`，不要再复制副本。
